# 緊急車両セーフティナビ（MVP）

緊急車両が一般車へ接近している状況を、画面注視を増やさずに通知するための実証用PWAです。現在は実車両の情報を使わず、東京駅付近の模擬データだけを使用します。

アプリアイコンは、中央を進む緊急車両と進路を譲る一般車を俯瞰図で表現しています。ブラウザのアイコン、ホーム画面追加時のアイコン、アプリ画面上部に表示されます。

## 安全・プライバシー上の仕様

- 最大500m以内かつ緊急車両が接近方向または予測衝突コースにある場合だけ警告
- 200m以内を緊急警告として区別
- 8秒より古い位置情報や100mを超える精度誤差は「情報不明」扱い
- 取得時刻やGPS精度が欠けた情報も、安全とみなさず「情報不明」扱い
- 50m以内では進行方向にかかわらず至近警告
- 「情報不明」を「緊急車両なし」と表示しない
- 走行モードでは操作ボタンを隠し、警告は短い音声を中心にする
- 停車中の模擬接近でも警告音と日本語音声を再生し、専用ボタンで音量確認ができる
- 後方約300mから近づく緊急車両の警告を画面と音声で確認できる
- 自車と緊急車両のアイコンに矢印で進行方向を示し、前方・後方の模擬位置を進行方向と一致させる
- 簡易地図では縦道の中心線に車両を配置し、道路上を走る見た目にする
- 目的地、車両番号、所属、移動履歴を取得・保存しない
- 現段階ではサーバーへ位置情報を送信しない
- 事故注意地点には、出典・期間・デモデータかどうかを表示する

## 起動

静的ファイルを配信できる任意のHTTPサーバーで起動してください。Pythonがある場合:

```sh
python -m http.server 4173
```

その後 `http://localhost:4173` を開きます。

## Google Mapsを有効にする

1. `config.example.js` を `config.js` にコピーします。
2. Google Cloudで Maps JavaScript API を有効にします。
3. HTTPリファラー制限を設定したAPIキーを `config.js` に記入します。

`config.js` はGitの追跡対象外です。キーがなくても簡易地図で安全ロジックを確認できます。本番では依存ライブラリを自己ホストし、APIキーの利用制限と予算上限を設定してください。

APIキー未設定でも、地図上の「Google Mapsで現在地を開く」リンクからGoogle Mapsアプリ／サイトへ連携できます。リンクを押した場合だけ座標がGoogleへ渡り、このアプリのサーバーには保存しません。

APIキー未設定時は、LeafletとOpenStreetMapの道路地図をアプリ内に表示します。画面上にはOpenStreetMapの著作権表示を常に表示し、通常の対話閲覧だけに使用します。地図タイルの一括取得・先読み・オフライン保存は行いません。大規模または商用の運用では、利用量に合ったタイル配信事業者または自己ホスト構成へ切り替えてください。

アプリを起動すると、ブラウザのGPS許可を得たうえで位置情報の継続取得を自動的に開始し、更新のたびに地図の中心と現在地マーカーを追従させます。「GPS追従を停止」ボタンで停止でき、許可しなかった場合も同じボタンから再試行できます。位置情報は端末内だけで扱い、デモシナリオを実行すると取得位置を基準に模擬接近を表示します。

自車の矢印はGPSが返す方位を優先し、方位を取得できない端末では連続する座標から移動方向を計算します。GPSの微小な位置ぶれや30秒を超える更新間隔では方向を推測せず、直前の矢印を維持します。

GPSはHTTPSまたはlocalhostでのみ利用できます。スマートフォンで使う場合は、HTTPS対応のホスティングへ公開し、ブラウザの位置情報許可を有効にしてください。

GPSの常時追従は電池を消費し、OSやブラウザのバックグラウンド制限で更新が止まることがあります。実運用では必要なときだけ開始し、終了時に停止してください。

ブラウザの自動再生制限に対応するため、起動後に画面を一度タップすると警告音が有効になります。「警告音をテスト」または各接近シナリオのボタンは、押すたびに二段階の警告音を再生します。

実証シナリオは現在地の周辺に模擬車両を配置しますが、端末の一時的なGPS精度不足や更新間隔に影響されないテスト値で判定します。通常のGPS安全判定では、従来どおり精度不足を「情報不明」として扱います。

## 検証

Node.js 20以降で次を実行します。

```sh
npm run verify
```

64種類の自動テストで、距離・方位、GPS移動方向、実証シナリオの分離、50m/200m/500m境界、接近・離反、交差点での予測衝突、データ鮮度、GPS精度不足、異常時刻・速度・座標、欠損データ、Google Maps・OpenStreetMapのマーカー更新、本番サーバーの公開範囲とセキュリティヘッダー、2,000通りのランダム入力を検証します。

## Google Cloud Runへの公開

本番サーバーはCloud Runの`PORT`環境変数に対応しています。Google Cloud CLIを設定した環境では、プロジェクトとリージョンを選択後に次のコマンドで公開できます。

```bash
gcloud run deploy emergency-vehicle-safety --source . --region asia-northeast1 --allow-unauthenticated
```

Cloud RunのHTTPS URL上では、ブラウザの位置情報許可を得てGPS追従を利用できます。`/healthz`はデプロイ後の稼働確認用です。

## 本番導入前に必要なこと

これは運転支援製品ではなく、実証用プロトタイプです。本番化には、消防・警察・自治体との正式連携、法務・プライバシー影響評価、専門家監修、閉鎖コースでの視線・反応時間テスト、障害時設計、第三者セキュリティ診断が必要です。
